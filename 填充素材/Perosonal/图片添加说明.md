# Personal 图片资源管理说明

## 文件命名规则

图片文件需按照以下格式命名：
```
[字母]-[编号].[扩展名]
```

其中：
- **字母**：A, B, C, D, E（不区分大小写）
- **编号**：阿拉伯数字
- **扩展名**：支持 jpg, jpeg, png, gif, webp 等常见图片格式

### 示例
- `A-1.jpg` - A 组第 1 张
- `B-3.png` - B 组第 3 张
- `E-10.jpg` - E 组第 10 张

## 更新图片步骤

### 1. 添加或替换图片
将新图片放入此文件夹（`Perosonal`）中，确保文件名符合上述格式。

### 2. 更新配置文件
打开同级目录下 `Code` 文件夹中的 `personal-images.json` 文件：

```json
{
  "images": [
    "A-1.jpg",
    "A-2.jpg",
    "B-1.jpg",
    ... 在此添加新图片文件名
  ],
  "basePath": "../填充素材/Perosonal/"
}
```

将新图片的文件名添加到 `images` 数组中。

### 3. 刷新页面
刷新浏览器页面，新图片将自动按照 A-E 的顺序显示。

## 排序规则

图片将按照以下规则自动排序：

1. **按首字母排序**：A 组最先，然后 B，C，D，E（不区分大小写）
2. **按编号排序**：同一字母组内按编号顺序排列（1, 2, 3, ...）

## 注意事项

- 文件名中的字母不区分大小写，`c-3.jpg` 和 `C-3.jpg` 会被视为同一组
- 编号可以是任意正整数，不要求连续
- 如需删除图片，从文件夹和配置文件中同时移除即可
