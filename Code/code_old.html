潮起高崎，文化共鸣

项目名称 厦门高崎海洋文化时尚艺术季
设计时间 2025.05-2025.12
项目地点 中国福建厦门高崎社
功能类型 文化艺术策展
主策划 熊晓龙、王思琦

厦门城市设计周高崎海洋文化时尚艺术季是依托高崎寨历史文脉、海洋文化和城市更新实践开展的综合性公共艺术活动，也是2025年厦门城市设计周分会场活动之一。

活动以“海·潮”为主题，通过19处公共空间艺术装置、开幕活动、主题沙龙、成果展示、导览打卡和公众互动等形式，联动政府、高校、社区、专家、艺术家与设计机构共同参与，探索以公共艺术激活社区空间、传播城市形象、提升公共文化服务的新路径。项目在策划和实施过程中，充分结合高崎寨海防历史、渔村记忆、社区空间现状与文旅融合需求，统筹完成调研、设计、施工、宣传和活动组织等工作，并兼顾安全、耐久、居民通行和后期维护。整体来看，艺术季提升了高崎寨公共空间识别度和文化氛围，增强了社会传播力和专业影响力，为打造高崎文化IP、推动艺术赋能城市更新积累了实践经验，也体现了政府、高校、社区和社会专业力量协同参与公共文化建设的价值。

山海の間

项目名称NOT A HOTEL 屋久岛度假设计
时间2020-11-12
状态日本建筑设计竞赛 (Yakushima, Japan)
类型酒店、景观、建筑
面积200㎡
团队梁凯翔、刘欢、李雪、丁雅馨

屋久岛位于日本九州岛的南端，是一个充满神秘色彩的海岛。岛上覆盖着茂密的原始森林，是宫崎骏动画《幽灵公主》的取景地。项目旨在在这片自然保护区内，设计一座融入环境、环保且具有独特体验的度假别墅。

设计灵感来源于岛上独特的自然景观：连绵的山脉和浩瀚的海洋。建筑主体犹如一块破土而出的岩石，与周围的地形地貌相呼应。屋顶采用当地传统的茅草覆盖，既能有效隔热，又能与自然景观融为一体。内部空间设计注重通透性和观景视野，大面积的落地窗将室外美景引入室内，模糊了室内外边界。
